# POTASSIUM_SERIAL_V3 — Phase1 protocol,19November2026

NEW exploratory analysis informed by V1/V2; not independent confirmation. This project is distinct from V3_FEASIBILITY. Preserve previous projects and raw sources. No outcome-effect calculation until the fixed100case/100control gate passes and a separate dated effect plan is frozen.

Sources: full provider record_list, full machine measurements, raw labevents item50971 (dictionary verified Blood/Chemistry), patients, admissions and ED stays. Hash exact inputs, original v2 extractor and all discovered extracted local header/data files. Hospital/ED release versions are unknown absent a release manifest. ECGv1.0 is indicated by source paths, not independently authenticated provider checksums. Physical clock synchronization stays unverified. No ICD selection in any group. No benchmark predictions or prior effects are used.

Laboratory matching: item50971 only; finite numeric1.5–10mmol/L-equivalent, supported explicit mEq/L or mmol/L, no comparator text, valid chart/store ordering, no explicit invalid/cancel/error comments. Hemolysis mentions are flagged but retained in primary eligibility, since a mention is not assay adjudication; Phase2 would exclude them as a sensitivity. Missing admission/specimen IDs and ambiguity are flags, not inferred verification. First choose nearest otherwise-valid lab from the same patient within ±30min, irrespective of its value/admission; tie-break absolute gap, earlier charttime, then lowest labevent_id. Do not search a more distant lab to rescue an admission mismatch. Different-valued same-time or equal-distance alternative results are flagged ambiguous and excluded. Choosing among equal ranks never depends on potassium magnitude. Missing or invalid units are excluded uniformly.

ECG eligibility: unique key, index/machine timestamp equality, age>=18 from anchor fields; unique containing hospital interval from earlier EDregistration/admission through discharge. ED intervals are independently audited; phase classification requires an actual ED stay with matching subject/admission if ECG precedes admission. Both target collection and ECG must be inside the same corroborated recorded hospital admission, with lab hadm nonmissing and equal to that interval. Missing hadm stays unknown and is excluded after matching. No clock-offset correction is fitted.

Pair rules: two eligible ECGs2–48h apart in that same admission. Either chronological order of abnormal/normal is allowed; the feature orientation would be abnormal minus normal, not inferred treatment response. Hyper>=5.5, hypo<3.5, reference normal3.5–5.0. Stable controls both3.5–5.0 and |deltaK|<=0.30 (1e-9 numerical tolerance). No minimum1mmol case change. Choose one shortest-interval pair per patient/group, tie-break earlier timestamp then chronological ECG IDs. Pair selection precedes waveform access and never uses ECG-derived features. Exclude control candidates belonging to any metadata-eligible case patient for disjoint arms, before QC; report hyper/hypo patient overlap. Do not replace failed/unavailable selected pairs.

Identical waveform rules all arms: both local header/data pairs; canonical named12leads,500Hz,5000samples,mV/positive calibration; digital checksum; original engineering QC <=1%nonfinite, each independent lead>=100finite/std>=0.01mV,99.5th-percentile |voltage|<=10mV; original v2 beat extraction with bounded gap repair, identical settings. Header acquisition time must agree with index; duplicated local copies must have equal hashes. Extracted RR defines original interval/RR strata, not a machine-RR substitute. Templates can be saved privately for QC, but do not calculate logRMS scores or effects during Phase1.

Common strata: ECG intervals[2,12),[12,24),[24,48]h crossed with |deltaRR|<=100,(100,200],>200ms; require>=3distinct patients in each arm per cell, as in historical estimand. Report care setting separately (actual corroborated ED/inpatient/mixed) and missingRR. Feasibility gate is >=100distinct cases AND >=100distinct disjoint stable controls summed over shared eligible strata, separately for hyper/hypo. No extra minimum-strata-count requirement and no relaxing the100/100rule. This operational gate is not a power guarantee.

If neither passes: stop. Do not calculate primary effects or15/60min sensitivity effects, confidence intervals or favorable-window searches. Publish a feasibility report and phase-status/empty sensitivity registry marked not activated. No article asserting an association. A later authorized retrieval may reassess fixed selected records, not swap pairs opportunistically. If a group passes, freeze a dated Phase2 plan before effects and include all requested windows, collection direction, hemolysis and source-time sensitivities, including null/unavailable results.
